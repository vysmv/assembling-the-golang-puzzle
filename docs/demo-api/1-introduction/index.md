# Введение

## Предисловие

Привет всем заглянувшим!

В этот раз мы разберем создание REST-API на Go.
За основу я взял понравившуюся мне книгу, написанную одним австрийским программистом.

По сути, тут будет мой опыт осмысления проекта из этой книги, но с моими модификациями.
Например, в отличие от книги, мы будем вести разработку, используя Докер, а не локальную установку всего, что нужно.
Также я буду отбрасывать ряд промежуточных состояний того или иного функционала, которые автор использовал для дополнительных пояснений.

Если же вы захотите прочесть и саму книгу, то дайте знать об этом в комментариях и укажите ваш email.

И также сразу на старте скажу, что предполагается, что у вас есть некий базовый уровень владения Go.
То есть это видео не содержит последовательного изучения Go как языка.
Это именно прикладное применение Go на примере создания REST-API.

Хорошо, с этим все, и поехали.

## Краткое описание проекта

В этом [цикле видео](https://www.youtube.com/playlist?list=PLVMpJVDMEBuI) мы сделаем [REST-API](https://github.com/vysmv/demo-api), которое позволит получать информацию о фильмах и управлять ими.

Итоговый набор эндпоинтов будет примерно такой:

(Слайд №1)

|  Метод | Шаблон URL                  | Действие                                                |
| :----: | :-------------------------- | :------------------------------------------------------ |
|   GET  | `/v1/healthcheck`           | Показать информацию о состоянии приложения и его версии |
|   GET  | `/v1/movies`                | Показать информацию обо всех фильмах                    |
|  POST  | `/v1/movies`                | Создать новый фильм                                     |
|   GET  | `/v1/movies/:id`            | Показать информацию о конкретном фильме                 |
|  PATCH | `/v1/movies/:id`            | Обновить информацию о конкретном фильме                 |
| DELETE | `/v1/movies/:id`            | Удалить конкретный фильм                                |
|  POST  | `/v1/users`                 | Зарегистрировать нового пользователя                    |
|   PUT  | `/v1/users/activated`       | Активировать конкретного пользователя                   |
|   PUT  | `/v1/users/password`        | Обновить пароль конкретного пользователя                |
|  POST  | `/v1/tokens/authentication` | Сгенерировать новый токен аутентификации                |
|  POST  | `/v1/tokens/password-reset` | Сгенерировать новый токен для сброса пароля             |
|   GET  | `/debug/vars`               | Показать метрики приложения                             |

С точки зрения клиента, к концу проекта API будет выглядеть так:

(Слайд №2)

* Запрос

```bash
$ curl -H "Authorization: Bearer RIDBIAE3AMMK57T6IAEBUGA7ZQ" localhost:8080/v1/movies/1
```

(Слайд №3)

* Ответ

```json
{
    "movie": {
        "id": 1,
        "title": "Moana",
        "year": 2016,
        "runtime": "107 mins",
        "genres": [
            "animation",
            "adventure"
        ],
        "version": 1
    }
}
```

Думаю, что этого достаточно для введения, и можем идти дальше.
